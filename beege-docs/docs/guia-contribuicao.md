# Guia de Contribuição

Para contribuir com o projeto BeeGe, siga as convenções abaixo:

## Padrão de Commits
Utilizamos o **Conventional Commits**:
- `feat:` Nova funcionalidade
- `fix:` Correção de bug
- `docs:` Alteração na documentação
- `style:` Formatação de código
- `refactor:` Refatoração (sem adicionar feature ou fix)

Exemplo: `feat: adiciona componente de listagem de universidades`

## Padrão de Branches
- `main` (código de produção)
- `feat/nome-da-feature`
- `fix/nome-do-bug`
- `docs/nome-do-documento`
